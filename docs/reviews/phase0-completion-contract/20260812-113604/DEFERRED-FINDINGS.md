## DEF-4 (확증) — `UNDECIDED` 차단이 §11 종료조건과 정면 충돌한다

### 실측

```
§7.4 (v1.6)   UNDECIDED  저작자가 키를 공급하지 못함 → 검사기가 자동 부여.
                         **D0-5 완료를 차단한다.** §13 등재로 면제되지 않는다

:1883 §11     | D0-5의 7개 사이트 전부가 `VALUED`/`BLOCKED`/`UNBOUND`/`UNDECIDED`
                중 하나를 검사기 파생으로 배정받음 |
                §7.4 — 완료 = "전부 해소"가 아니라 "전부 판정" |
```

**§7.4는 `UNDECIDED`가 완료를 막는다고 하고, §11은 `UNDECIDED` 배정도 완료 조건
충족이라고 한다.** 같은 상태에 두 계약이 반대 판정을 낸다.

§11의 "완료 = 전부 해소가 아니라 **전부 판정**"이라는 문구 자체가 v1.6 이전 모델의
잔재다 — v1.6은 `UNDECIDED`를 "판정"이 아니라 **"미분석"**으로 재정의했고, 그것이
차단 승격의 근거였다.
