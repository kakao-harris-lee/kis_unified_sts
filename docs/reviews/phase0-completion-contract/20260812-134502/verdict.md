```

                                                    ↑ blocks_gate 가 아니다
```

**뮤테이션 대상이 `normative_ref` 다.** 따라서:

> **모든 normative id 를 모든 게이트의 사유 집합에 넣고 `blocks_gate` 를 전혀 읽지
