## 0. 왜 «처방 없이» 등재하는가

여섯 판 연속으로 처방을 냈고 **여섯 번 다 반증**됐다.

| 판 | 처방 / 주장 | 반증한 것 |
|---|---|---|
| 초판 | `P2` — 면제를 «인용(mention)»으로 | `«»` 로 감싸면 조용 → **회귀** |
| rev.1 | `P2′` — 면제를 «블록 상속»으로 | 태그 블록 안의 주장 → **회귀** |
| rev.2 | `P3`(전역 기수) · §3.1 경계 닫힘 | 장식용 태그 1개 → 조용 / L103 재삽입 → 위반 0 |
| rev.3 | `P3′`(주장 행 기수) · §4-6 오라클 대조군 | 주장 행 «안»의 장식 → 조용 / **진리표만으로 반증** |
| 분할판 | `P1+P1-D` — 「제거이므로 회귀 불가능」 | **배터리 자신이 기준선을 잘못 잡았다**(아래 §4) |

**「등재는 차단이 아니다」가 이 아크의 규율이지만, «검증되지 않은 처방»은 차단보다 나쁘다.**
여섯 번의 실패가 전부 «닫았다»를 적고 그것을 시험하는 입력을 돌리지 않아서 났다.
**그래서 이 문서는 측정만 적는다.**

## 1. F-MARK — 실측 사실 (35차 ⓵ 등재분)

`LAYER_MARK_RES`(C4B 가드)는 층 태그 · `vX.Y 동결 내용` · `«…» 층` · `층 구분` 과 **함께**
`[vX.Y 에라타 N차` 를 센다.  앞의 넷은 «어느 층의 말인가»를 선언하지만 provenance 괄호는
«언제 적었는가»만 말한다.  **극성이 귀결이다** — 많이 편집한 행일수록 더 확실히 면제된다.

**실측**: provenance 정규식만 빼면 **C4B 위반 2건**(L97 · L103)이 새로 발생한다.

| 행 | 다른 층 마커 | 정체 |
|---|---|---|
| L96 · L4940 · L4941 · L5151 | **있음** | — |
| **L97** | **없음** | 「6차까지 이 자리는 «재심 미착수»였고」 — 과거 시제 이력 서술 |
| **L103** | **없음** | 35차 ⓶ 가 상대 참조로 고친 자리 |

**이것은 «사실»이고 «처방»이 아니다.**  아래 §4 가 그 처방이 왜 서지 않는지를 잰다.

## 2. F-CARD — 무엇이 문제인가 (34차 ⓶ 등재분)

`C4A`·`C4C` 는 둘 다 `check_c4` 의 `if tags:` **안**이라 층 태그 기수가 0 이면 **축 하나와
limb 하나가 통째로 침묵**한다.

| | 태그 보유 행 | C4C 모집단 | 검사기 |
|---|---|---|---|
| 기준 | 4 | 1 | **PASS · rc 0** |
| `LAYER_TAG_RE` 매치 전부 치환 | **0** | **0** | **PASS · rc 0 · 위반 0** |

**제약(34차 ⓶)**: 「태그 0 → red」로 단순히 적으면 **처방 방향(정본을 문서 «밖»으로)이 영구
red 가 되어 목표가 도달 불가**가 된다.  닫는 술어는 **«태그 0»과 «주장 0»을 갈라야 한다.**

### 2.1 시도된 술어 둘과 반증

```text
P3   red ⟺ (주장 > 0) ∧ (문서 전역 층 태그 == 0)
     반증: 태그 전멸 후 «무관한 행»에 현행 태그 하나 → claims=6 · tagged=1 → 조용
P3′  red ⟺ (주장 > 0) ∧ (주장 행 중 층 태그 보유 == 0)
     반증: 태그 전멸 후 «주장 행 안»에 HTML 주석 `<!-- 장식용: 현행(**37차 이후**) -->`
           → claims=6 · bound=1 · 위반 0
```

**공통 결함**: 기수를 **존재 술어(`> 0`)** 로 두었다.  **하나만 있으면 나머지 전부가
보호받는 것처럼 보인다.**

### 2.2 다음 후보의 «즉시 위양성» (측정 — 처방 아님)

심판 권고 방향은 **전수 불변식**(`bound == claims` 또는 행별 요구)이다.
**오늘 그대로 쓰면**: 주장 행 6 · 층 태그 보유 4 · **태그 없는 주장 행 2**(L97 · L103).
그 둘은 `«…» 층` 마커만 갖는 자리이고 `«…» 층` 은 **`LAYER_TAG_RE` 가 아니다.**
⟹ 전수 불변식을 쓰려면 **그 두 행에 «실제 층 태그»가 필요**하고, 그러면 **매 회차 `C4A`
갱신 대상이 4 → 6 으로 는다.**  **대가를 재는 데까지가 이 문서의 범위다.**

## 3. F-POS · 어휘 선언 축소 · `C4A` 형상 한정

### 3-1 F-POS (C4C 위치 기반 provenance 면제)

| 면제 형태 | 우회 |
|---|---|
| 위치 기반 (현행) | provenance **뒤**에 쓰면 조용 (같은 문장을 앞/뒤 주입 → RED / 조용) |
| mention 기반 | `«»` 로 감싸면 조용 |
| 블록 상속 | C4C 모집단은 «셀» — **적용 불가** |

정당한 면제(L4941 의 「종래 «8차 이후» 를 리터럴로 적었고」)는 성격이 **과거 인용**이고
저작자가 타이핑하는 것이다.  **세 회차에 걸쳐 구조로 가르지 못했다.**

### 3-2 어휘 선언 축소 — **선재**

currency 어휘는 **L96 한 자리**의 `「미착수/재심 전」 어휘` 선언에서 파생된다.  좁히면
「미착수」 주장이 스윕 밖이 된다.  **현행·처방 «동등»** — 어떤 C4 처방도 이것을 넓히지도
좁히지도 않는다.  닫으려면 「선언 자체를 앵커로 잠근다」가 필요하다.

### 3-3 `C4A` 는 «형상만» 본다

「현행 층 = N차 이후」 형상은 `현행(N차 이후)` 태그 형상이 아니라 `C4A` 사정거리 밖이다.

## 4. **F-MARK 의 두 처방 후보가 «상충»한다** — 이 문서의 핵심 실측

분할판(문서 A)이 낸 처방은 `P1`(provenance 를 마커에서 제거) + `P1-D`(그것이 드러내는
두 행에 `«…» 층` 마커를 단다)였다.  **심판이 그 배터리의 «기준선»이 틀렸음을 적발했다** —
현행 열을 **P1-D 가 이미 적용된 문서** 위에서 계산했다(§5).

**올바른 입력 쌍으로 재측정한 결과가 이것이다.**

```text
현행     = 원본 문서            + 현행 검사기
P1 단독  = 원본 문서            + P1 검사기
P1+P1-D  = P1-D 적용 문서        + P1 검사기
```

| # | 뮤턴트 | 현행 | **P1 단독** | **P1+P1-D** |
|---|---|---|---|---|
| ① | 무변경 (기준 위양성) | 0 | **2** | **0** |
| ② | 무태그 살아 있는 주장 | RED | RED | RED |
| ③ | **provenance 만 단 주장** | 조용 | **RED** | **RED** |
| ④ | `«»` 로 감싼 주장 | RED | RED | RED |
| ⑤ | 무태그 인용 블록 안 | RED | RED | RED |
| ⑥ | 태그 있는 블록 안 | RED | RED | RED |
| ⑦ | 표 셀 안의 주장 | RED | RED | RED |
| ⑫ | **L97 provenance 구문 파손** | RED | RED | **조용 ★회귀** |
| ⑬ | L97 provenance 제거 | 조용 | 조용 | 조용 |
| ⑧ | 층 태그 전부 제거 | 조용 | RED※ | 조용 |

```text
P1 단독   :  회귀 0 · 강화 1(③) · 그러나 **기준 위양성 2**
P1+P1-D   :  기준 위양성 0 · 강화 1(③) · 그러나 **회귀 1(⑫)**
```

**⟹ 두 후보가 상충한다.  «위양성 0»과 «회귀 0»을 동시에 주는 안이 이 문서에는 없다.**

* **⑫ 가 P1-D 의 정체를 드러낸다** — `P1-D` 는 두 행에 마커를 **추가**하므로 그 두 행에
  대한 **면제 확대**다.  이 축에서 면제 확대는 커버리지를 줄인다.
  **「제거이므로 회귀 불가능」은 `P1` «단독»에만 성립하고 `P1+P1-D` 에는 성립하지 않는다.**
* **※ ⑧ 의 `P1 단독` RED 를 «F-CARD 닫힘»으로 읽으면 안 된다** — 그 RED 는 ① 의 **위양성
  2건이 그대로 남은 것**이지 기수 축이 발화한 것이 아니다.  **계수의 «색»을 «원인»으로 읽지
  않는다.**
* **⑬ 이 알려주는 것**: `L97` 의 C4B 모집단 «소속»은 **그 행의 provenance 괄호 안에 있는
  `v2.22` 리터럴**에 걸려 있다.  provenance 를 통째로 지우면 버전 리터럴도 사라져 그 행이
  모집단에서 빠진다 — **모집단 소속과 면제가 «같은 문자열»에 의존한다.**  이 결합 자체가
  등재 대상이다.

## 5. 메타 검증 — 「현행 열」을 어떻게 얻는가 · **두 번 실패했다**

규율은 이것이다: `회귀 ≡ 현행 RED ∧ 처방 조용 → 차단`.
**이 규율이 두 판을 살렸다**(P2·P2′ 의 회귀가 이것으로 잡혔다).  문제는 **그 두 값을 어떻게
얻는가**이고, 두 번 다 틀렸다.

### 5.1 실패 ① — 판정식이 논리적으로 반대였다 (rev.3 §4-6)

```python
assert not (legacy_red and not current_red)
```

| `legacy_red` | `current_red` | 통과? |
|---|---|---|
| True | True | **True** |
| False | False | **True** |
| True | False | False |
| False | True | **True** |

동결 튜플을 current 와 같게 만들면 `legacy_red == current_red` 이므로 **항상 참**이다.
⟹ **오라클을 죽인 뮤턴트가 self-test 를 «통과»시킨다.**  **뮤턴트조차 필요 없이 진리표만으로
반증된다.**

### 5.2 실패 ② — **입력 쌍 자체가 틀렸다** (분할판 · 이 track 최악의 결함)

배터리가 `cur(BT)` vs `new(BT)` 였고 `BT` 는 **P1-D 가 이미 적용된 처방 문서**다.
즉 «현행» 열을 **처방본 위에서** 계산했다.

| 입력 조합 (뮤턴트 ⑫) | L97 |
|---|---|
| **현행 문서 + 현행 검사기** | **RED** |
| 처방 문서 + P1 검사기 | 조용 |
| **틀린 배터리의 `cur(BT)`** | **조용 — 회귀를 볼 수 없었다** |

**`rev.2` · `rev.3` · 분할판의 배터리가 전부 같은 형태였다.**
⟹ **다섯 라운드 동안 선언한 «회귀 0» 은 그 위에서 성립하지 않는다.**

**교훈(성문화)**: **대조군은 «판정식»과 «입력 쌍»을 둘 다 검산해야 한다.**
「대조군을 돌린다」를 네 판에 걸쳐 성문화하는 동안 **그 대조군 자신을 한 번도 검산하지
않았다.**

### 5.3 남은 후보 (등재 · 검증하지 않음)

* 심판 권고 — 동결 legacy 는 그대로 둔 채 **current 쪽에 알려진 회귀를 주입**하고 내부
  회귀 판정이 **반드시 실패**하는 메타 대조군을 정의한다.  결과는 **단일 aggregate boolean 이
  아니라 규칙과 발화 자리까지 비교**한다.
* 더 약한 대안 — 뮤턴트별 현행 결과를 **상수로 못박는 «핀»**.  **핀은 저작자가 편집할 수
  있고**, 차이는 **핀 편집이 diff 에 보이는 상수 변경**이라는 것뿐이다.

**둘 다 이 문서가 검증하지 않았다.  적어만 둔다.**

## 6. 관측 범위 — **정확히 무엇이 «매 실행» 보이는가**

분할판이 「⑧·⑨ 가 미닫힘을 매 실행 관측한다」고 적었는데 **과잉이다**(심판 F-H, 채택).
정확히 적는다:

| 축 | 상시 관측면 |
|---|---|
| F-CARD | ⑧ (층 태그 전멸) — **다만 §4 의 ※ 주의: `P1 단독`에서는 위양성이 색을 가린다** |
| 어휘 선언 축소 | ⑨ |
| **F-POS** | **없음** — 어느 배터리 행도 provenance 전후 위치 우회를 실행하지 않는다 |
| **메타 검증(핀·오라클)** | **없음** |

**열린 위험을 «등재»한 것과 그 위험을 «지속 관측»하는 것은 다르다.**
F-POS 와 메타 검증은 **등재만 돼 있고 관측되지 않는다.**

## 8. 이 문서가 요청하는 판정

**«채택»을 요청하지 않는다.  처방이 없기 때문이다.**  요청하는 것은 둘이다:

1. **등재가 정확한가** — §1 의 실측, §2.1 의 두 반증과 §2.2 의 즉시 위양성 2건,
   **§4 의 3열 배터리와 «두 후보 상충» 판정**, §5 의 두 실패, §6 의 관측 범위.
   **틀린 계수나 과잉 주장이 있는가.**  특히 §4 의 ※ 와 ⑬ 은 «계수의 색을 원인으로 읽지
   않는다»는 규율의 자기 적용이다.
