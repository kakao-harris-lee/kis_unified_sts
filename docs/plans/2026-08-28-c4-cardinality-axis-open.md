## 0. 왜 «처방 없이» 등재하는가

이 축에서 **네 판 연속으로 처방을 냈고 네 번 다 반증됐다.**

| 판 | 처방 | 반증한 뮤턴트 |
|---|---|---|
| rev.2 | `P3` — 「문서 전역 층 태그 == 0」 이면 red | **무관한 행의 장식용 태그 1개** → 조용 (F-A) |
| rev.3 | `P3′` — 「주장 행 중 태그 보유 == 0」 이면 red | **주장 행 «안»의 HTML 주석 장식** → 조용 (F-D) |
| rev.2 | `§4` 동결 오라클 | 「기준 오라클이 정의되지 않았다」 (F-C) |
| rev.3 | `§4-6` 오라클 대조군 | **진리표만으로 반증** — 오라클을 죽인 뮤턴트가 통과 (F-E) |

**「등재는 차단이 아니다」가 이 아크의 규율이지만, 「검증되지 않은 처방」은 차단보다 나쁘다** —
네 번의 실패가 전부 «닫았다»를 적고 그것을 시험하는 뮤턴트를 돌리지 않아서 났다.
**그래서 이 판은 측정만 적고 처방을 내지 않는다.**

## 1. F-CARD — 무엇이 문제인가 (34차 ⓶ 등재분)

`check_c4` 의 `C4A`·`C4C` 는 둘 다 `if tags:` **안**에 있다.  층 태그 기수가 0 이면
**축 하나와 limb 하나가 통째로 침묵**한다.

**실측**:

| | 태그 보유 행 | C4C 모집단 | 검사기 |
|---|---|---|---|
| 기준 | 4 | 1 | **PASS · rc 0** |
| `LAYER_TAG_RE` 매치 전부 치환 | **0** | **0** | **PASS · rc 0 · 위반 0** |

⟹ **래칫이 읽는 «성공 상태»(위반 0)가 «축 전멸»과 구별되지 않는다.**

**그리고 34차 ⓶ 이 못박은 제약이 있다**: 「태그 0 → red」로 단순히 적으면 **처방 방향
(정본을 문서 «밖»으로)이 영구 red 가 되어 목표가 도달 불가**가 된다.  닫는 술어는
**«태그 0»과 «주장 0»을 갈라야 한다.**

## 1.1 시도된 술어 둘과 그 반증 (실측)

```text
P3   red ⟺ (주장 > 0) ∧ (문서 전역 층 태그 == 0)
     반증: 태그 전멸 후 «무관한 행»에 현행 태그 하나 → claims=6 · tagged=1 → 조용
P3′  red ⟺ (주장 > 0) ∧ (주장 행 중 층 태그 보유 == 0)
     반증: 태그 전멸 후 «주장 행 안»에 HTML 주석 `<!-- 장식용: 현행(**37차 이후**) -->`
           → claims=6 · bound=1 · 처방 위반 0 · 현행 위반 0
```

**둘의 공통 결함**: 기수를 **존재 술어(`> 0`)** 로 두었다.  **하나만 있으면 나머지 전부가
보호받는 것처럼 보인다.**

## 1.2 다음 후보와 그 «즉시 위양성» (측정 — 처방 아님)

심판이 권고한 방향은 **전수 불변식**이다(`bound == claims` 또는 행별 요구).
**오늘 그대로 쓰면 즉시 위양성이 난다**:

```text
주장 행 6 · 층 태그 보유 4 · **태그 없는 주장 행 2** → L97 · L103
```

그 둘은 **P1-D 가 «층 마커»를 다는 바로 그 행**이고, `«…» 층` 은 `LAYER_MARK_RES` 일 뿐
**`LAYER_TAG_RE` 가 아니다.**  ⟹ **전수 불변식을 쓰려면 그 두 행에 «실제 층 태그»를 달아야
하고, 그러면 그 둘이 매 회차 `C4A` 갱신 대상이 되어 lockstep 이 4 → 6 으로 는다.**

**대가를 재는 것까지가 이 문서의 범위이고, 고르는 것은 다음 저작의 일이다.**

## 2. 메타 검증 — 「현행 열」을 실행 시점에 어떻게 얻는가

분할 출처가 세운 규율은 이것이다:

```text
회귀 ≡ 현행 RED ∧ 처방 조용   → 차단.  어떤 이유로도 처방에 넣지 않는다
```

**이 규율이 두 판을 살렸다**(P2·P2′ 의 회귀가 이것으로 잡혔다).  문제는 **구현 시점**이다 —
처방이 `LAYER_MARK_RES` 를 바꾼 «뒤»에는 `check_c4` 가 더 이상 «현행»을 계산하지 않는다.

## 2.1 시도된 설계와 그 반증

rev.3 §4 는 **동결 튜플 + `_c4b_legacy()`** 를 두고, 각 사례가 legacy·current 를 둘 다
계산해 다음을 강제하게 했다:

```python
assert not (legacy_red and not current_red)
```

그리고 §4-6 에 **「동결 튜플을 current 와 같게 만드는 뮤턴트를 넣어 회귀 검출이 죽으면
self-test 가 실패함을 보인다」**를 적었다.  **그것은 논리적으로 반대다.**

| `legacy_red` | `current_red` | `assert` 통과? |
|---|---|---|
| True | True | **True** |
| False | False | **True** |
| True | False | False |
| False | True | **True** |

동결 튜플을 current 와 같게 만들면 `legacy_red == current_red` 이므로 위 식은 **항상 참**
이다.  ⟹ **오라클을 무력화한 바로 그 뮤턴트가 self-test 를 «통과»시킨다.**

**뮤턴트조차 필요 없이 진리표만으로 반증된다** — 「대조군을 돌린다」를 세 판에 걸쳐
성문화하면서 **정작 그 대조군의 판정식은 검산하지 않았다.**

## 2.2 심판이 준 방향 (등재 · 검증하지 않음)

> 동결 legacy 는 그대로 둔 채 **current 쪽에 알려진 회귀를 주입**하고 내부 회귀 판정이
> **반드시 실패**하는 메타 대조군을 정의하라.  결과는 **단일 aggregate boolean 이 아니라
> 규칙과 발화 자리까지 비교**해 새 `C4-CARD` 위반이 `C4B` 손실을 가리지 못하게 하라.

**이 방향을 이 문서는 «검증하지 않았다».  적어만 둔다** — 검증하지 않은 것을 처방으로
적지 않는 것이 이 축의 네 번의 실패가 남긴 교훈이다.

## 2.3 «핀»이라는 더 약한 대안 (문서 A 가 쓴 것)

`2026-08-28-c4-p1-provenance-marker-design.md` §4-4 는 오라클 대신 **뮤턴트별 현행 결과를
상수로 못박는 «핀»** 을 쓴다.  **핀은 저작자가 편집할 수 있고 그 문서는 그것을 자인한다.**
차이는 **핀 편집이 diff 에 보이는 상수 변경**이라는 것뿐이다.
**그 대안이 이 축(F-CARD)에 충분한지는 이 문서가 판단하지 않는다.**

## 3. 인접 미닫힘 — 함께 등재한다

### 3-1 F-POS (C4C 위치 기반 provenance 면제)

| 면제 형태 | 우회 |
|---|---|
| 위치 기반 (현행) | provenance **뒤**에 쓰면 조용 (실측: 같은 문장을 앞/뒤에 주입 → RED / 조용) |
| mention 기반 | `«»` 로 감싸면 조용 |
| 블록 상속 | C4C 모집단은 «셀» — **적용 불가** |

정당한 면제(L4941 의 「종래 «8차 이후» 를 리터럴로 적었고」)는 성격이 **과거 인용**이고
저작자가 타이핑하는 것이다.  **세 회차에 걸쳐 구조로 가르지 못했다.**

### 3-2 어휘 선언 축소 — **선재**

currency 어휘는 **L96 한 자리**의 `「미착수/재심 전」 어휘` 선언에서 파생된다.
좁히면 「미착수」 주장이 스윕 밖이 된다.  **현행·처방 «동등»** 이므로 어떤 C4 처방도
이것을 넓히지도 좁히지도 않는다.  닫으려면 「선언 자체를 앵커로 잠근다」가 필요하다.

### 3-3 `C4A` 는 «형상만» 본다

「현행 층 = N차 이후」 형상은 `현행(N차 이후)` 태그 형상이 아니라 `C4A` 사정거리 밖이다.

## 4. 이 문서가 요청하는 판정

**이 문서는 «채택»을 요청하지 않는다.  처방이 없기 때문이다.**  요청하는 것은 둘이다:

1. **등재가 정확한가** — §1.1 의 두 반증, §1.2 의 즉시 위양성 2건, §2.1 의 진리표,
   §3 의 세 인접 미닫힘.  **틀린 계수나 과잉 주장이 있는가.**
2. **«처방 없이 등재»가 이 축에서 타당한 처분인가** — 네 번의 반증 뒤에 다섯 번째 처방을
   내지 않는 것이 신중인가 태만인가.

**이 문서가 열려 있는 동안 `F-CARD`·`F-POS`·메타 검증은 «미닫힘»이고, 그 사실은
문서 A 의 배터리 ⑧·⑨ 가 매 실행에서 관측면으로 보인다.**
