## 0. rev.1 이 «철회»하는 것 — 먼저, 그리고 크게 적는다

초판 머리말은 **「이 초안이 «닫는다»고 주장하는 것: ⑧ 이 등재한 처방의 부재」**라고 적었다.
**그 주장을 철회한다.**  심판 F-2 가 그 자리를 정확히 짚었다 — 강제 축(C5)이 미설계인 채로는
①ⓒ′ 가 **강제되지 않는 산문**이고, 그러면 «처방의 부재»는 닫히지 않는다.

초판은 또 **「정의역 확장은 `U` 전체」**라고 적었다.  **그 범위도 철회한다.**  심판 F-1 이
옳다 — `U-6`(세계 변화)은 ①ⓒ 의 정당화가 **닿지 않는** 자리이고, 초판의 정본 표에는
**`U-6` 행 자체가 없었다**(자기 처방이 자기가 발견한 클래스를 덮지 못했다).

**rev.1 이 «주장하는» 것은 이것뿐이다:**

```text
① ⑧ 의 다섯 자리 중 «자기참조» 클래스 넷(U-1·U-2·U-4·U-5)에 대해
   처방의 «방향»은 계약 ①ⓒ 안에 이미 있고, 그 정당화가 그대로 전이된다.
② U-6 은 «다른 원인»의 문제이며 ①ⓒ 로는 닿지 않는다 — 그것을 실측으로 보인다.
③ 강제 축(C5)은 미설계다.  따라서 «처방의 부재»는 «좁아졌을» 뿐 «닫히지» 않았다.
```

**「좁혔다」와 「닫았다」를 같은 문장에 쓰지 않는다**(35차 ⓸ 의 규율).

## 2. 요건 이행 (34차) — 「계약이 이미 등재했는가」

물었고 답이 있었다.  S-26 ①ⓒ 다.

> **ⓒ 종결 기입 예외 — ①-연장판의 자기참조 교착.** … **«종결»도 판정**이므로 그 규칙대로면
> 종결을 기입하는 순간 주장 시점 blob 이 변해 **①-연장판이 그 선언 자신에 의해 거짓이 된다**.

## 3. 정당화가 «어디까지» 전이되는가 — 자리별 검증 (F-1 처분)

```text
U  ≡  「계약 본문을 편집하지 않으면 거짓·부재가 되는 자리」의 집합.
```

옮길 «안정한 정본»이 존재하지 않는다.  **⟹ ①ⓒ 는 U-6 에 닿지 않는다.  F-1 이 옳다.**

### 3.1 그래서 처방의 범위를 좁힌다

```text
①ⓒ′  판정·상태의 «정본»은 문서 «밖»(원장·아티팩트)에만 두고 본문에 기입하지 않는다.
      본문은 그것을 «가리키기»만 한다.
      정의역 = { U-1, U-2, U-4, U-5 }   ← «자기참조» 클래스에 한정한다.
      종결 기입(①ⓒ 원문)은 그 넷과 같은 구조의 다섯 번째다.
```

**어휘를 새로 만들지 않았다** — ①ⓒ 의 문장을 그대로 쓰고 정의역만 «명시»했다.
그리고 **초판처럼 `U` 전체로 넓히지 «않는다».**

에라타 36차도 같은 이유로 그 처방을 **범위 밖**으로 두었다.  **등재하고 넘긴다.**

## 5. 강제 축 C5 — **미설계다.  그래서 «닫혔다»고 적지 않는다** (F-2 처분)

29차 누적 요건은 「**참조 문장을 보는 검사 축** 신설」이다.  본문이 값을 **다시 갖는 것**을
막을 축이 없으면 ①ⓒ′ 는 강제되지 않는 산문이다(K-10).

```text
C5  본문의 U 자리들이 «가리키는 문장»인가 «값»인가를 본다.
    red ⟺ 정의역의 어느 자리가 정본 필드의 값을 «리터럴»로 보유한다.
```

**C5 가 져야 할 짐 넷을 이 문서는 하나도 지지 않았다** — 심판 F-2 의 열거를 그대로 받는다:

| 짐 | 상태 |
|---|---|
| 닫힌 모집단 (`U` 의 **기계** 정의) | **없음** — §3 의 `U` 는 산문 정의다 |
| «값 vs 참조» 판별 술어 | **없음** |
| fail-closed 극성 | **미정** |
| §6 이 공개한 우회 셋에 대한 대조군 | **없음** |

⟹ **이 문서는 «처방의 부재»를 닫지 않는다.**  닫은 것은 **방향의 미확정**뿐이고, 그것도
**자기참조 클래스에 한정**된다.  **형상 정규식을 여기서 발명하지 않는다** — 그것이 초안 1 이
fail-open 으로 죽은 자리다.

## 5.1 U-5 「현재 위치」 — 한 쌍은 갈렸고 두 쌍은 확인하지 않았다

29차 ⓶ 는 상태→행 사상이 **함수가 아니다**로 초안 3 을 기각했다
(`ENTRY_OK` → 7|8 · `REBINDING_REQUIRED` → 6e⁗|7c · `APPROVAL_*` → 6c‴|7c).

**한 쌍은 갈린다.**  6e⁗ 은 **P-0 «전»**, 7c 는 **P-0 «후»** 재진입이고 그 비트는 문서 밖에서
관측 가능하다 — `U-15-g-1` 의 판정 우주 `D` 다.

```
config/tos_completion.yaml : 부재 · 그 경로 도입 커밋(--full-history) : 0
D0A-FIRST «실제 트레일러» : 0        ⟹  D = ∅  ⟹  P-0 미착수  ⟹  6e⁗
```

오늘 두 리터럴이 **둘 다 6e⁗** 을 가리키고 하니스도 `REBINDING_REQUIRED` 다 — **정합**.
**그러나 나머지 두 쌍은 갈리는 비트를 찾지 않았다.**  한 쌍이 갈린다고 사상이 함수가 되지
않는다.  **U-5 는 열린 채로 등재한다**(28차가 허용한 선택지).

> **naive grep 함정 기록**: `git log --all --grep="D0A-FIRST"` 는 **0 이 아닌 값**을 낸다.
> 전부 그 이름을 **언급한** 설계·증거 커밋이고 **실제 트레일러(`^D0A-FIRST:`)는 0** 이다.
> 계수를 그대로 썼으면 「P-0 착수됨」이라는 정반대 결론이 나왔다.
>
> **계수 리터럴을 적지 않는다 — 이 자리가 그 이유를 스스로 실증했다.**  초판은 여기에
> 「**10건**」이라 적었는데, **그 문장을 담은 커밋 자신이 «D0A-FIRST» 를 한 번 더 언급해
> 계수를 11 로 만들었다.**  즉 **그 리터럴은 기입되는 순간 stale 이 되는 종류**다.
> 16차의 약(「값 갱신이 아니라 리터럴 «제거»」)을 여기에 적용해 **갱신할 값 자체를 없앤다.**
> 대조가 필요하면 아래 §8 의 두 명령을 돌린다 — **판정은 «언급 > 0 ∧ 트레일러 == 0»** 이다.

## 6. 「어떻게 공허하게 만족시킬 것인가」 — 심판보다 먼저 (S-2)

* **가장 싼 우회는 «가리키는 문장»에 값을 싣는 것**이다 — 「현행 판정은 `needs-attention`
  이며 산출물은 X 다」는 형식이 참조인데 **값이 본문에 산다**.  **C5 가 미설계이므로 이 우회는
  오늘 열려 있다**(§5).
* **두 번째는 «아티팩트를 본문 안에 인용»하는 것**이다.  ①ⓒ 는 «기입»만 말하고 이 형상을
  **금지하지 않는다** — 정의역을 좁혀도 이 구멍은 함께 물려온다.
* **세 번째는 `U` 의 정의를 좁히는 것**이다.  `U` 는 산문 정의이고 기계가 세지 않는다.
  자리를 «U 밖»이라 부르면 규범이 닿지 않는다.
* **넷 다 C5 가 져야 할 짐이고 C5 는 없다.**  그래서 §0 이 «닫았다»를 철회한 것이다.

## 7. 선행 의존 — C4 별건과 «합»으로만 성립한다

34차 ⓶ 이 등재한 대로, 목표 상태(값이 본문에서 나감)는 F-CARD 가 열려 있는 한 «축의 사망»과
구별되지 않는다(실측: 층 태그 전부 제거 → PASS).  그 별건 설계(`2026-08-27-c4-layer-marker-
mention-design.md` **rev.1**)의 `P3` 이 그것을 가른다.

**그 별건도 같은 판정에서 `needs-attention` 을 받았고 rev.1 로 개정됐다** — 초판 P2 를
«회귀»로 재분류하고 P2′ 로 갈아탔다.  **따라서 이 문서 §3.1 은 여전히 그 재심에 조건부다.**

```bash
  -q '.[] | select(.name|test("tos")) | "\(.name)\t\(.conclusion)\t\(.event)"'

# §5.1 — D = ∅ 인가 (naive grep 과 «실제 트레일러»를 반드시 갈라 센다)
git log --all --full-history --oneline -- config/tos_completion.yaml | wc -l   # 0
git log --all --grep="D0A-FIRST" --oneline | wc -l                             # > 0 — «언급»
git log --all --format="%H%n%b" --grep="D0A-FIRST" | grep -c "^D0A-FIRST:"     # 0 — «실제»
# 판정 = «언급 > 0 ∧ 실제 == 0».  앞 값은 회차마다 늘므로 리터럴로 적지 않는다(§5.1).
```

## 9. 이 초안이 요청하는 판정

1. **§3 의 «자리별 전이 검증»이 F-1 을 처분하는가** — 정의역을 자기참조 넷으로 좁히고
   U-6 을 정의역 «밖»으로 옮긴 것이, 「①ⓒ 에서 도출됨을 입증하거나 새 술어로 판정하라」는
   Recommendation 을 만족하는가.  **rev.1 은 «도출되지 않는다»를 택했다.**
2. **§0·§5 의 철회가 F-2 를 처분하는가** — 「닫았다」를 걷어내고 C5 의 짐 넷을 «지지 않았다»로
   명시한 것이 정직한 이연인가, 아니면 요건 회피인가.
3. **§4 가 U-6 에 «처방 없이 관측만» 두는 것이 타당한가** — 후보(10차 ⓓ)를 알면서 쓰지 않은
   것이 신중인가 태만인가.
4. **§7 의 조건부성** — 이 문서는 여전히 재심받지 않은 별건 rev.1 에 의존한다.
