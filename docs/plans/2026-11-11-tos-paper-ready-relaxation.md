## 2. 새 판정

**문장 1 — 무인 운용 (완화).** LONG 트리에서 최근 40일 창 안 **깨끗한 거래일 누적 5일**.
깨끗한 하루 = 그 거래일 세션이 cron(또는 `@reboot` catch-up)으로 기동해 정지 시각까지 돌고 run rc ∈ `clean_run_rcs`.
- **연속은 요구하지 않는다.** 깨진 날(LOST·FAILED·세션 없음)은 그날만 세지 않고 앞의 기록을 지우지 않는다.
- **B3 는 돌았는지만 본다.** `b3/status.json` 이 있으면 된다. unresolved · divergent 는 상태판에 계속 «확인»으로
  나오지만 깨끗함 판정에서 빠진다(B3 는 레거시 증인과의 대조이지 과정의 동작 조건이 아니다).
- SHORT 는 세지 않는다(운영자가 켠 추가 트리).

**문장 2 — 주문 경로 하나 (완화).** 주식 MOCK 진입 주문 **1건**이 결정 → standing 승인 → RCL 예약 → verify →
`kis_mock` 전송 → ACK → 체결 관측(`FILL_OBSERVED`) → finality 까지 간다.
- **신호 출처는 묻지 않는다.** Setup D 가 아니어도 된다 — 주식 트리의 설정 게이트 진입 규칙
  (`R4-M2-PROBE-ENTRY-LONG`, 바인딩 1/0)으로 낸 제안도 같은 경계를 지나므로 인정한다.
- 청산 체결은 요구하지 않는다(일어나면 기록한다).
- 달성한 다음 거래일 전에 바인딩을 0 으로 되돌리는 한 줄 PR 을 낸다.

**문장 3·4·5** — 그대로(이미 참).

**M4 (완화).** 12-10 롤을 포함한 10 거래일 창을 없앤다. 문장 1·2 가 참이 되는 날 상태판 한 화면으로 확인하고
`TOS_PAPER_READY` 를 선언한다(운영자 서명 1줄). 11-13 첫 CP-3 롤은 관찰 대상이지 판정 조건이 아니다.
