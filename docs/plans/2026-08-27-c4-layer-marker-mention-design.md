## 3. 처방 — 셋으로 줄어든다 (초판은 셋이었으나 내용이 다르다)

### P1 — `LAYER_MARK_RES` 에서 provenance 를 제거한다 (F-MARK)

provenance 괄호는 «언제 적었는가»만 말하고 «어느 층의 말인가»를 선언하지 않는다.
**초판이 함께 «추가»하려던 «상대 참조» 마커는 폐기한다** — 아래 P2′ 가 그 자리를 덮으므로
불필요하고, 축자 문구 마커는 그 자체로 24차 클래스다.

### P2′ — 면제를 «인용»이 아니라 «블록 앞머리 층 태그의 상속»으로 준다 (F-MARK)

```text
exempt(행 i) ⟺ (a) 그 행 자체에 층 마커가 있다
              ∨ (b) 그 행이 속한 인용 블록(= `^\s*>` 의 최대 연속) 앞머리 쪽에
                    **실제 `LAYER_TAG_RE` 태그**가 존재한다
```

**이 술어는 인용·강조·시제를 «전혀» 보지 않는다.**  `«»` 도, 과거형도, 저작자가 타이핑하는
어떤 문구도 면제를 켜지 못한다 — 켜는 것은 **실제 층 태그의 존재**뿐이고 그 태그는
`C4A` 가 현행 회차와 대조한다.  **우회는 «축 사이 이동»이지 «탈출»이 아니다.**

### P3 — 기수 극성을 «축별로» 정의한다 (F-CARD)

```text
C4-CARD  red  ⟺  (currency 주장 행 > 0)  ∧  (층 태그 보유 행 == 0)
```

34차 ⓶ 의 요구(«태그 0»과 «주장 0»을 가른다)를 그대로 만족하고, 처방 방향의 목표 상태
(주장 0)가 **영구 red 가 되지 않는다**.  세 번째 상태는 **술어의 형상에서 따라 나오는 것**
이지 대조군으로 잰 것이 아니다 — 그렇게 적는다.

## 5. 닫지 «않는» 것 — 등재

### 5-1 **F-POS (C4C) 는 닫지 못한다 — 초판의 주장을 철회한다**

초판은 「한 술어가 두 축을 닫는다」로 적었다.  **거짓이다.**  C4C 의 면제를 어떤 형태로
두어도 **저작자가 위조할 수 있다**(실측 셋):

| 면제 형태 | 우회 |
|---|---|
| 위치 기반 (현행) | provenance 뒤에 쓰면 조용 (M4) |
| mention 기반 (초판 P2) | `«»` 로 감싸면 조용 (M5) |
| 블록 상속 (P2′) | **C4C 의 모집단은 «셀» 이라 블록 개념이 없다 — 적용 불가** |

**C4C 의 정당한 면제(L4917 의 「종래 «8차 이후» 를 리터럴로 적었고」)는 그 성격이
«과거 인용»이고, 과거 인용은 저작자가 타이핑하는 것이다.**  구조로 가를 방법을 이 회차는
찾지 못했다.  **F-POS 는 열린 채로 남는다.**

### 5-2 P2′ 의 우회 — «태그 있는 블록 안에 stale 주장을 쓴다»

⑥ 이 보여주듯 태그 있는 블록 안은 조용하다.  거기에 stale 주장을 쓰면 C4B 는 안 본다.
**그러나 그 블록의 태그 자체는 `C4A` 가 현행 회차와 대조**하므로, 층이 낡으면 `C4A` 가
red 를 낸다.  **닫힌 것은 아니고 «다른 축이 받는다»** — 그렇게 적는다.
**«받는다»와 «막는다»는 다르다**: 태그가 현행인 블록 안의 stale 주장은 **어느 축도 보지 않는다.**

### 5-3 어휘 선언 축소 — **선재 구멍이며 이 설계가 넓히지 않는다**

F-3 이 지목한 우회다.  currency 어휘는 **L96 한 자리**의 `「미착수/재심 전」 어휘` 선언에서
파생되고, 그것을 `「재심 전」` 으로 좁히면 「미착수」 주장은 스윕 밖이 된다.

**실측 — 극성을 가른다**:

| 검사기 | 선언 그대로 | 선언 축소 |
|---|---|---|
| **현행(무변경)** | RED | **조용** |
| **이 처방 적용 후** | RED | **조용** |

⟹ **선재 구멍이고 이 설계는 그것을 «넓히지도 좁히지도» 않는다.**
**§0 의 P2 회귀와 정확히 반대 극성이며, 그 구별을 적는 것이 이 절의 요점이다.**
닫으려면 「선언 자체를 앵커로 잠근다」가 필요하고 그것은 **별건**이다.

### 5-4 `C4A` 는 여전히 «형상만» 본다

35차 ⓶ 가 고친 자리의 형상(「현행 층 = N차 이후」)은 `현행(N차 이후)` 태그 형상이 아니라
`C4A` 사정거리 밖이다.  P3 이 **기수 축**을 닫고 §4.1 이 **그 한 자리**를 닫지만,
**«태그 형상 밖 층 선언»의 stale 일반**은 여전히 어느 축도 보지 않는다.

### 5-5 `--report` 의 「C4B 모집단」은 검사되는 모집단이 아니다 (부수)

`narrowed` 는 `is_history_row` 필터 **앞** 계수라 7 을 출력하지만 실제 검사 모집단은 6 이다.
보고 문언 정정 대상으로 등재한다 — 처방은 여기서 내지 않는다.

### 5-6 인용 블록 정의의 경계를 검증하지 않았다

P2′-(b) 는 블록을 `^\s*>` 의 최대 연속으로 정의한다.  **중첩 인용(`> >`)과 표 셀 안의
인용은 대조군을 돌리지 않았다.**  이 코퍼스에 그 형상이 있는지도 세지 않았다.

## 7. 재현 — **실행 가능한 코드** (F-3 후단 처분)

초판 §7 은 M1 만 실행 가능했고 나머지는 import 힌트였다.  **전 배터리를 한 스크립트로 낸다.**

```bash
cd <repo>
.venv/bin/python - <<'PY'
import importlib.util, re
spec = importlib.util.spec_from_file_location('cc', 'tools/tos_contract_check.py')
cc = importlib.util.module_from_spec(spec); spec.loader.exec_module(cc)
D = 'docs/plans/2026-08-12-tos-phase0-completion-contract-design.md'
text = open(D, encoding='utf-8').read()

QUOTE = re.compile(r'^\s*>'); TAG = cc.LAYER_TAG_RE
BASE = tuple(rx for rx in cc.LAYER_MARK_RES if '에라타' not in rx.pattern)   # P1

def blk(L, i):                                                              # P2'
    if not QUOTE.match(L[i]): return False
    j = i
    while j >= 0 and QUOTE.match(L[j]):
        if TAG.search(L[j]): return True
        j -= 1
    return False

def run(t):
    d = cc.ContractDoc(t, '<c>'); L = d.lines; v = []; claims = 0; tagged = 0
    for n, line in enumerate(L, 1):
        if TAG.search(line): tagged += 1
        if not any(x in line for x in d.currency_terms): continue
        if not any((int(m.group(1)), int(m.group(2))) >= d.current_version
                   and int(m.group(1)) == d.current_version[0]
                   for m in cc.VERSION_LITERAL_RE.finditer(line)): continue
        if d.is_history_row(n): continue
        claims += 1
```

## 8. 이 문서가 요청하는 판정

1. **§0 의 철회가 충분한가** — P2 를 «회귀»로 재분류하고 P2′ 로 갈아탄 것이, F-3 의

   닫혔다고 판정하지 말라」)을 만족하는가.  **④ 는 red 다.  ⑧ 은 조용이고 §5-3 이 그것을
   «선재»로 가른다** — 그 가름이 타당한가, 아니면 회피인가.
2. **§5-1 의 철회(F-POS 는 닫지 못한다)가 정직한가**, 아니면 축소해 놓고 «닫았다»로
   읽히게 두었는가.

4. **§7 배터리가 실제로 실행되는가** (F-3 후단).
